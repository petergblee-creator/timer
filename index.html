목소리 바꾸기 (갤럭시)
  1. 구글 음성 서비스(Speech Services by Google) 설치·업데이트
  2. 폰 설정 → 일반 → 텍스트 음성 변환 (검색창에 「텍스트 음성」 입력해도 됨)
  3. 기본 엔진 → 「Google 음성 인식 및 합성」 선택
  4. 엔진 옆 ⚙ → 음성 데이터 설치 → 한국어 → 목소리 받기 (남자 목소리 포함)
  5. 이 앱을 껐다 켜고 아래 「목소리」 목록에서 고르기
삼성 엔진을 쓰려면 3번에서 「삼성 TTS 엔진」 → ⚙ → 음성 데이터 설치.
